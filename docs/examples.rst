Examples
========

Each example solves one problem and checks the result against a closed form
or a reference solution. Its page states the problem, lists the script and
shows the output. The scripts are in the ``examples`` directory of the
repository and need only NumPy, SciPy and TTNumPy. The test suite runs every
one of them.
